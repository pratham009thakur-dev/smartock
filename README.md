# SmartStock 📦

A full-stack inventory management application developed using Next.js 14 and React for small and medium-sized businesses[cite: 1].

## 🛠 Tech Stack
- **Framework**: Next.js 14 (App Router), React[cite: 1]
- **Languages**: JavaScript, CSS3, HTML5[cite: 1]
- **Architecture**: REST API Routes, Modular Component Architecture[cite: 1]
- **Version Control**: Git, GitHub[cite: 1]

## ✨ Core Features
- **Product Lifecycle Management**: Built REST API routes handling complete create, read, update, and delete (CRUD) operations alongside real-time inventory tracking[cite: 1].
- **Analytics Dashboard**: Designed an analytics dashboard to visualize inventory status and business insights[cite: 1].
- **Modular Component Architecture**: Implemented modular component architecture for scalability and future feature expansion[cite: 1].

## 🚀 Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/pratham009thakur-dev/smartstock.git
   ```
2. Navigate into the directory and install dependencies:
   ```bash
   cd smartstock
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
